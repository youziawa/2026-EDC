# 1×4按键板接线与操作

## 适用按键板

本文按“4个独立常开按键，共用一个GND”的无源按键板配置，即模块至少引出：

```text
K1  K2  K3  K4  GND
```

这类按键板不需要接VCC。若手里的模块只有 `VCC/GND/OUT` 三根线，或带电阻分压模拟输出，
不要按本文接线；它需要ADC方案，应先确认原理图或模块照片。

## 接线

四个信号选用小车主控右侧H3排针连续的5～8脚，均未被电机、编码器、K230、I2C或蓝牙占用：

| 按键板 | 功能 | STM32 | 小车主板排针 |
|---|---|---|---|
| K1 | 选择抛投任务 | PE5 | H3-5 |
| K2 | 选择动态起降任务 | PE3 | H3-6 |
| K3 | 开始任务 | PC0 | H3-7 |
| K4 | 中止并复位到待机 | PC2 | H3-8 |
| GND/COM | 公共地 | GND | H3-19 |

接线示意：

```text
按键板 K1  ───────── H3-5  / PE5
按键板 K2  ───────── H3-6  / PE3
按键板 K3  ───────── H3-7  / PC0
按键板 K4  ───────── H3-8  / PC2
按键板 GND ───────── H3-19 / GND
```

不要把任何按键信号接5V。接线和插拔前先关闭小车电源。

## CubeMX工程配置

`CarF407.ioc` 已加入以下配置：

| 引脚 | GPIO模式 | 上下拉 | 标签 |
|---|---|---|---|
| PE5 | Input | Pull-up | `TASK_DROP_KEY` |
| PE3 | Input | Pull-up | `TASK_LAND_KEY` |
| PC0 | Input | Pull-up | `TASK_START_KEY` |
| PC2 | Input | Pull-up | `TASK_RESET_KEY` |

因此按键松开时输入为高，按下后通过公共地变为低。软件统一转换为“按下=1”，并进行20 ms
非阻塞消抖，不使用按键中断，也不会阻塞循线、速度环或通信任务。

## 比赛操作

1. 上电后小车保持待机和停车。
2. 按K1选择抛投，或按K2选择动态起降；直接选择，不需要循环菜单。
3. 将小车放在A点并确认飞机、K230和两条蓝牙链路正常。
4. 短按K3，小车进入原有10 s安全撤离倒计时；倒计时结束后开始任务。
5. 任何阶段短按K4，小车立即停车、清除里程和故障、返回待机；若任务已经开始，
   同时向飞机和地面站发送当前 `run_id` 的 `TASK_ABORT`。
6. 复位后重新按K1或K2选题，再按K3开始下一轮。

任务开始后K1/K2不再改变模式，避免比赛途中误触切题。K4优先级最高；即使与其他键同时按下，
也只执行中止复位。
