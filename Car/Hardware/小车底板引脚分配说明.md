## 3. 各接口详细连接

### 3.1 驱动板 E1 编码器接口——当前左轮（原右电机）

建议底板连接器至少引出：

| 驱动板丝印 | STM32连接 | 当前含义 |
|---|---|---|
| `E1A` | PB6 / TIM4_CH1 | 左轮编码器A相 |
| `E1B` | PB7 / TIM4_CH2 | 左轮编码器B相 |
| `ENC_3V3` | 3.3 V | 编码器电源 |
| `ENC_GND` | GND | 编码器地 |

TIM4 配置为编码器模式 `TI1 and TI2`，A/B 两相输入滤波均为 4，输入预分频为 DIV1。

### 3.2 驱动板 E2 编码器接口——当前右轮（原左电机）

| 驱动板丝印 | STM32连接 | 当前含义 |
|---|---|---|
| `E2A` | PA5 / TIM2_CH1 | 右轮编码器A相 |
| `E2B` | PA1 / TIM2_CH2 | 右轮编码器B相 |
| `ENC_3V3` | 3.3 V | 编码器电源 |
| `ENC_GND` | GND | 编码器地 |

TIM2 配置为编码器模式 `TI1 and TI2`，A/B 两相输入滤波均为 4，输入预分频为 DIV1。

编码器输出电平必须确认不超过 STM32 GPIO 的允许输入电压。如果编码器输出为 5 V，必须增加电平转换或确认模块已经有 3.3 V 电平输出。

### 3.3 编码器四根信号线接线顺序

```text
驱动板 E1A → STM32 PB6  / TIM4_CH1
驱动板 E1B → STM32 PB7  / TIM4_CH2
驱动板 E2A → STM32 PA5  / TIM2_CH1
驱动板 E2B → STM32 PA1  / TIM2_CH2
驱动板 GND → STM32 GND
```

这里按驱动板的 `E1` 对应电机1/PWMA通道、`E2` 对应电机2/PWMB通道整理。当前软件中电机1是左轮、电机2是右轮。首次通电必须架空车轮验证；若驱动板厂家实际将E1/E2与电机通道交叉标注，应整组交换E1与E2，不能只交换单根A/B相。

### 3.4 TB6612 电机驱动接口

TB6612 使用两路独立 PWM、四路方向 GPIO 和一路 STBY 使能：

| TB6612 输入 | STM32 引脚 | 作用 |
|---|---|---|
| PWMA | PA8 / TIM1_CH1 | 当前实体左电机调速 |
| AIN1 | PB0 / GPIO_Output | 当前实体左电机方向 |
| AIN2 | PB1 / GPIO_Output | 当前实体左电机方向 |
| PWMB | PB15 / TIM12_CH2 | 当前实体右电机调速 |
| BIN1 | PB12 / GPIO_Output | 当前实体右电机方向 |
| BIN2 | PB13 / GPIO_Output | 当前实体右电机方向 |
| STBY | PB14 / GPIO_Output | 高电平使能驱动 |

软件控制逻辑：

```text
当前左电机正转：AIN1 = 0，AIN2 = 1，PWMA = PWM
当前左电机反转：AIN1 = 1，AIN2 = 0，PWMA = PWM
当前右电机正转：BIN1 = 0，BIN2 = 1，PWMB = PWM
当前右电机反转：BIN1 = 1，BIN2 = 0，PWMB = PWM
停止：对应 PWM = 0，方向脚均为 0
待机：STBY = 0
使能：STBY = 1
```

TIM1 当前配置：

```text
TIM1 时钟：168 MHz
Prescaler：0
Counter Period：8399
PWM 频率：20 kHz
CH1 初始 Pulse：0
```

TIM12 当前配置：

```text
TIM12 时钟：84 MHz
通道：CH2（PB15）
Prescaler：0
Counter Period：4199
PWM 频率：20 kHz
CH2 初始 Pulse：0
```

PB0、PB1、PB12、PB13、PB14 均配置为推挽输出，初始化电平为低。生成代码会在 GPIO 切换为输出模式前先写入低电平，避免初始化期间误驱动电机。

若临时将天空星核心板插在“筑基学习板”上测试，PB0/PB1 与板载 HX711/外部 ADC 排针复用，需要将 SW7 的 BIT2 切到外部 ADC 排针通道；使用自制小车底板直接连接天空星核心板时不涉及该切换。

TB6612 的 VM、VCC、GND、AO1/AO2、BO1/BO2 必须按照实际模块原理图连接。

### 3.5 MPU6050 接口

| MPU6050 信号 | STM32 引脚 | 说明 |
|---|---|---|
| SCL | PB8 / I2C1_SCL | 400 kHz |
| SDA | PB9 / I2C1_SDA | 400 kHz |
| INT | PB5 | 当前未启用，可选 |
| VCC | 3.3 V | 确认模块供电范围 |
| GND | GND | 共地 |

I2C 总线建议在底板上使用外部上拉：

```text
PB8/SCL → 4.7 kΩ → 3.3 V
PB9/SDA → 4.7 kΩ → 3.3 V
```

如果采用 TIM6 定时读取 MPU6050，可以不接 INT。若后续使用数据就绪中断，将 PB5 配置为 EXTI5 上升沿输入，并在底板连接器上预留该信号。

MPU6050 的 AD0 建议接地，使 7 位 I2C 地址为 `0x68`。HAL 调用时使用左移后的地址 `0xD0`。

### 3.6 小车 K230 串口

| K230端 | STM32F407端 | 接线方向与说明 |
|---|---|---|
| GPIO32 / UART3_TXD（K230 TX） | PB11 / USART3_RX | K230 TX → STM32 RX |
| GPIO33 / UART3_RXD（K230 RX） | PB10 / USART3_TX | STM32 TX → K230 RX |
| GND | GND | 必须共地 |
| K230 供电 | 按模块要求 | 不要直接假设为 3.3 V |

TX和RX必须交叉连接，不能TX接TX：

```text
K230 GPIO32 / UART3_TXD → STM32 PB11 / USART3_RX
K230 GPIO33 / UART3_RXD ← STM32 PB10 / USART3_TX
K230 GND                 ↔ STM32 GND
```

当前K230代码在 `vision_config.py` 中固定为：

```python
UART_CHANNEL = 3
UART_TX_PIN = 32
UART_RX_PIN = 33
```

串口配置：

```text
USART3
115200 baud
8 data bits
No parity
1 stop bit
No hardware flow control
```

USART3 使用 DMA：

```text
RX：DMA1_Stream1 / Channel 4 / Circular
TX：DMA1_Stream3 / Channel 4 / Normal
```

### 3.7 1×4任务按键板

任务控制改用无源、共地的1×4独立按键板：

| 按键 | STM32 | 主板位置 | 功能 |
|---|---|---|---|
| K1 | PE5 | H3-5 | 选择抛投 |
| K2 | PE3 | H3-6 | 选择动态起降 |
| K3 | PC0 | H3-7 | 开始任务 |
| K4 | PC2 | H3-8 | 中止并回到待机 |
| COM/GND | GND | H3-19 | 公共地 |

四个GPIO均使用内部上拉，松开为高、按下为低，软件使用20 ms非阻塞消抖。
K3保留10 s安全撤离倒计时；K4立即停车、清里程和故障，并向飞机和地面站发送
`TASK_ABORT`。详细接线和操作见
[`1x4按键板接线与操作.md`](1x4按键板接线与操作.md)。

天空星板载PA0按键继续保留为硬件输入，但不再触发任务。PA0不连接编码器；右轮
编码器E2A仍必须接PA5。

### 3.8 飞机通信接口

| 飞机端ECB02信号 | STM32 引脚 | 说明 |
|---|---|---|
| ECB02 TX | PA3 / USART2_RX | STM32 接收 |
| ECB02 RX | PA2 / USART2_TX | STM32 发出 |
| GND | GND | 必须共地 |

### 3.9 地面站通信接口

| 地面站模块信号 | STM32 引脚 | 说明 |
|---|---|---|
| 地面站ECB02 TX | PA10 / USART1_RX | STM32 接收 |
| 地面站ECB02 RX | PA9 / USART1_TX | STM32 发出 |
| GND | GND | 必须共地 |

串口配置同样为：

```text
USART1
115200 baud
8N1
无硬件流控
```

这里仅保留控制、状态和协议通信，不包含旧的地面站图传系统。

#### 快速接线诊断

新固件会通过USART1以10 Hz发送 `CAR_DIAGNOSTIC(0x34)`。可使用小车—地面站
ECB02链路接收，也可在断开该ECB02后临时直连USB-UART：

```text
STM32 PA9  / USART1_TX → USB-UART RX
STM32 PA10 / USART1_RX ← USB-UART TX（只监听时可不接）
STM32 GND               ↔ USB-UART GND
串口：115200、8N1
```

不要让ECB02 TX和USB-UART TX同时驱动PA10。电脑端运行
`2026-EDC/LXS1_通信协议/python/car_diagnostic_monitor.py`，即可判断PA0按键、
PWM/STBY、左右电机、E1/E2编码器以及K230串口是否有响应。

## 5. 电源、下载和保护建议

### 5.1 STM32 电源

底板绘制时必须处理：

- 所有 `VDD` 接 3.3 V。
- 所有 `VSS` 接数字地。
- `VDDA` 接经过滤波的 3.3 V。
- `VSSA` 接模拟地，并与系统地合理汇接。
- 每个 VDD 附近放置 100 nF 去耦电容。
- 芯片附近增加 4.7～10 uF 的电源储能电容。
- `VCAP_1`、`VCAP_2` 按 STM32F407 数据手册连接低 ESR 电容到地，不要接到其他电源。
- `NRST` 预留复位按键和下载器连接点。
- `BOOT0` 默认通过电阻下拉到地，并预留跳线到 3.3 V 的启动配置。

### 5.2 SWD 下载接口

建议底板预留五针或六针 SWD 接口：

```text
3V3
GND
SWDIO → PA13
SWCLK → PA14
NRST
```

### 5.3 电机和数字电路布线

- 电机电源和 STM32 3.3 V 电源分区布线。
- TB6612 与电机之间的高电流回路尽量短、宽。
- 编码器 A/B 线远离电机电源线和 PWM 线。
- MPU6050 放在车体刚性较好、振动较小的位置。
- 编码器、K230、MPU6050、无线串口模块必须与 STM32 共地。
- 所有外部输入信号在确认电平前，不要直接接入 STM32。

## 6. 当前未使用或预留引脚

当前工程没有使用的 GPIO 不要在底板上随意复用。建议：

- 未使用引脚按 CubeMX 默认模拟输入或无连接处理。
- 需要扩展时优先预留测试焊盘，不要直接连接到强驱动信号。
- PB5 作为 MPU6050 INT 预留。
- PA13、PA14 必须保留给 SWD，不能用于普通 GPIO。
- PH0、PH1 属于天空星核心板的板载高速晶振连接，当前工程使用内部 HSI，底板不需要连接这两个引脚。
- PA9、PA10 已分配给 USART1 地面站ECB02，不能再作普通GPIO。

当前工程未分配的主要 GPIO 包括 PA4、PA11、PA12、PA15，PB2～PB5，以及大部分 PC、PD、PE 端口。其中 PB5 已预留为可选的 MPU6050 INT，不建议再分配给其他固定功能。

## 7. 画板前最终检查

- [ ] 确认 STM32 实际封装为 LQFP100。
- [ ] 确认底板不连接 HSE，系统时钟使用天空星核心板 MCU 内部 HSI。
- [ ] 确认 TB6612 AIN1/AIN2 已改接 PB0/PB1，不再连接 PA10/PA11。
- [ ] 确认 MG310 编码器输出电平。
- [ ] 确认E2A已经由PA0迁移到PA5，PA0只连接板载KEY。
- [ ] 确认 TB6612 模块的 PWMA/PWMB、AIN1/AIN2、BIN1/BIN2、STBY 引脚定义。
- [ ] 确认 TB6612 的 VM 电机电源、电流能力和 MG310 堵转电流匹配。
- [ ] 确认 K230 串口电平和供电要求。
- [ ] 确认 MPU6050 模块已经有或底板提供 I2C 上拉。
- [ ] 预留 SWD、复位、BOOT0、串口测试点。
- [ ] 检查电机电源、逻辑电源和地线的电流回路。

> 说明：当前工程没有使用 USB、SDIO 或 RNG 等 48 MHz 外设，因此 PLLQ 对现有小车功能没有影响。若后续增加 USB 等外设，应重新设置 PLLQ，使 48 MHz 专用时钟满足外设要求。
