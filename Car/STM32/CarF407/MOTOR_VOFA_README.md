# 双轮同速与 VOFA+ 联调说明

## 当前功能

- TIM1_CH1 / PA8：当前实体左轮（原右电机）20 kHz PWM。
- TIM12_CH2 / PB15：当前实体右轮（原左电机）20 kHz PWM。
- PB0、PB1：当前实体左轮 TB6612 方向。
- PB12、PB13：当前实体右轮 TB6612 方向。
- PB14：TB6612 STBY，高电平使能。
- TIM4 / PB6、PB7：当前实体左轮编码器。
- TIM2 / PA5、PA1：当前实体右轮编码器（E2A、E2B）。
- PA0：天空星板载KEY，松开为低、按下为高，用于启动任务。
- USART2 / PA2、PA3：飞机ECB02；USART1 / PA9、PA10：地面站ECB02。

当前 `CAR_DEFAULT_TARGET_PPS` 为 `40000`、`CAR_MAX_TARGET_PPS` 为 `100000`。
程序上电约 2 秒后开始软启动，按照每秒增加 `5000 pps` 的斜坡逐渐加速。
若要进行安全的手动编码器检查，应先将默认目标改为 `0`。左右轮使用
独立 PI 速度闭环，PWM 最大限制为 60%。

启用巡线后，默认直行目标不会直接驱动车轮。`LineFollow_Init()` 会先执行
紧急停车，只有 USART3 收到 K230 的有效巡线帧后才会设置左右轮目标。

## 车轮与编码器标定

实测车轮直径约 `47 mm`，高强度新版底板的两轮接地点中心轮距为 `432 mm`。
手动旋转一整圈得到：

- 当前左轮（原右电机，TIM4）：约 `+41589` 原始计数/圈。
- 当前右轮（原左电机，TIM2）：约 `-41348` 原始计数/圈。
- 左右每圈计数差约 `0.58%`。

按轮周长 `π × 47 ≈ 147.655 mm` 计算：

- 左轮：`1 count ≈ 0.003550 mm`。
- 右轮：`1 count ≈ 0.003571 mm`。
- `20000 pps ≈ 71.2 mm/s ≈ 28.9 rpm`。
- `50000 pps ≈ 178.0 mm/s ≈ 72.3 rpm`。

里程计计算时必须分别使用左右轮的每计数距离，不能用同一个平均比例；编码器
原始正负方向则由 `CAR_LEFT_ENCODER_SIGN` 和 `CAR_RIGHT_ENCODER_SIGN` 修正。

差速里程计每个更新周期使用：

```text
左轮路程 dL = 左轮修正后计数 × CAR_LEFT_MM_PER_COUNT
右轮路程 dR = 右轮修正后计数 × CAR_RIGHT_MM_PER_COUNT
中心路程 dS = (dL + dR) / 2
航向变化 dTheta = (dR - dL) / 432
```

其中 `dTheta` 的单位为弧度。理论原地旋转90°时，每个轮子需要行驶约
`339.292 mm`，对应左轮约 `95575` 计数、右轮约 `95035` 计数；实车应再根据
轮胎打滑进行旋转标定。

实车测试曾出现“一轮狂转，手转另一轮后两轮交替启停”。该现象说明电机输出
与编码器反馈形成了交叉闭环，因此软件已按实体车轮重新配对：

- 左轮闭环：TIM4 编码器 → PA8 PWM + PB0/PB1 方向。
- 右轮闭环：TIM2 编码器 → PB15 PWM + PB12/PB13 方向。

## 第一次上电前

第一次运行必须先把车轮架空，不要直接把小车放在地上。确认：

1. TB6612 的 VM、VCC、GND 和 STBY 已正确连接，STM32、编码器和驱动共地。
2. 飞机ECB02接USART2，地面站ECB02接USART1，并与STM32共地。
3. 编码器输出电平不超过 STM32 引脚允许范围。

当前更换底板后两只轮子的机械安装方向均反转，因此软件已经同时反转两侧
电机方向和编码器方向。当前设置为：

- `CAR_LEFT_FORWARD_IN1_HIGH = 0U`
- `CAR_RIGHT_FORWARD_IN1_HIGH = 0U`
- `CAR_LEFT_ENCODER_SIGN = -1`
- `CAR_RIGHT_ENCODER_SIGN = +1`

如果以后恢复原来的机械安装方向，应将电机方向和对应编码器方向成对恢复，
不能只修改其中一项。

若车轮方向正确，但 VOFA+ 中该轮速度为负数，将对应方向宏在 `1` 与 `-1`
之间切换：

- 左编码器方向：`CAR_LEFT_ENCODER_SIGN`。
- 右编码器方向：`CAR_RIGHT_ENCODER_SIGN`。

交换左右电机后，当前实体左轮接入 TIM4、当前实体右轮接入 TIM2。按当前安装，
方向修正设置为左轮 `+1`、右轮 `-1`；向前运行时仍以 VOFA+ 通道2、3均为
正数为准。

目标速度为 `0` 时，程序会同时将 PWM 清零、方向脚清零并把 STBY 拉低。若
MCU 刚上电或复位时仍然出现瞬间转动，应在 TB6612 的 STBY 与 GND 之间增加
约 `10 kΩ` 下拉电阻，因为软件无法控制 MCU 进入 `main()` 之前的引脚状态。

程序检测到“向前驱动但编码器持续为负”时会关闭 STBY。故障码：

- `1`：左编码器方向错误。
- `2`：右编码器方向错误。
- `3`：左右编码器方向都错误。

## VOFA+ 配置

1. 新建串口设备，选择 USB 转串口对应的 COM 口。
2. 波特率选择 `115200`，数据位 `8`，停止位 `1`，无校验。
3. 协议引擎选择 `FireWater`。
4. 每行十七个通道，顺序为：

```text
平均目标,左轮速度,右轮速度,左轮PWM,右轮PWM,故障码,
TIM4周期计数,TIM2周期计数,TIM4累计计数,TIM2累计计数,
左轮目标,右轮目标,巡线状态,横向误差,航向误差,转向修正,置信度
```

前六个通道的单位分别为 `pps, pps, pps, 千分比, 千分比, 位标志`。
通道7、8是最近一个20 ms控制周期内的原始有符号计数；通道9、10是
从上电开始累计的原始有符号计数。调试编码器时应比较通道9、10的绝对值，
累计计数不受手动转轮速度快慢影响。

巡线相关通道含义：

- 通道11、12：左右轮实际采用的斜坡目标，单位 pps。
- 通道13：`0` 安全停车，`1` 有效跟踪，`2` 短时丢线保持。
- 通道14：横向误差，单位 mm，正数表示黑线位于车体右侧。
- 通道15：航向误差，单位 deg，正数表示需要向右修正。
- 通道16：差速修正，单位 pps，正数表示右转。
- 通道17：K230 置信度，范围 0～1000。

正常情况下，前三条曲线中的左右轮速度应逐渐靠近目标速度。若左右速度仍有稳定偏差，先检查轮胎、负载和编码器，再调整 `car_control.c` 中的 `SPEED_KP`、`SPEED_KI`。

## 主要可调参数

参数位于 `Core/Inc/car_control.h`：

- `CAR_DEFAULT_TARGET_PPS`：上电默认目标速度。
- `CAR_PWM_MAX_PERMILLE`：最大 PWM，第一次调试建议不要超过 600。
- `CAR_TARGET_RAMP_PPS_PER_SECOND`：目标速度爬升率。
- `CAR_LEFT_ENCODER_SIGN`、`CAR_RIGHT_ENCODER_SIGN`：编码器方向。
- `CAR_LEFT_FORWARD_IN1_HIGH`、`CAR_RIGHT_FORWARD_IN1_HIGH`：电机向前逻辑。

PI 参数位于 `Core/Src/car_control.c`：

- `SPEED_FILTER_ALPHA`
- `SPEED_KP`
- `SPEED_KI`
- `LEFT_SPEED_FF_OFFSET`
- `LEFT_SPEED_KFF`
- `RIGHT_SPEED_FF_OFFSET`
- `RIGHT_SPEED_KFF`
- `PWM_SLEW_PER_CONTROL_STEP`
