# K230 小车巡线联调说明

## 已实现的数据链路

```text
K230 灰度图巡线
  -> UART3，115200 8N1，40 Hz
  -> STM32 USART3_RX / PB11，循环 DMA
  -> 固定19字节帧解析
  -> 横向误差 + 航向误差 + 曲率前馈
  -> 左右轮独立目标速度
  -> 双轮 PI 速度闭环
  -> TB6612
```

K230 GPIO32（UART3_TXD）接 STM32 PB11（USART3_RX）；
K230 GPIO33（UART3_RXD）接 STM32 PB10（USART3_TX），两块板必须共地。
当前视觉结果主要使用K230 TX方向，但保留RX连接用于后续参数下发。

协议沿用 `Car/K230/lxs1_uart.py`：

```text
AA 55 | 0E | 05 | 04 | 42 |
valid | lost | confidence(u16) | lateral(i16) |
heading(i16) | curvature(i16) | marker(u8) | 0D 0A
```

多字节字段均为小端，不使用校验和或 CRC。横向误差、航向误差和曲率为
正数时都表示需要向右修正。

`marker=1`表示K230在已锁定轨迹附近看到大黑圆点。小车仅在累计里程达到
7300 mm后把它作为A点完成标志，B/C/D处保持巡线，不会停车。

## 控制策略

- 先用K1/K2选择抛投或动态起降，再按K3开始；小车先保持电机关闭10 s。倒计时结束后，如果起步位置暂时
  看不到A点圆点或普通线，小车以40 mm/s直行搜索；识别到普通线后立即切换
  正常巡线，3 s仍无有效线则停车，最大盲行距离约120 mm。
- K230 有效且置信度不低于 380：进入跟踪。
- 置信度越高，基础速度在 12000～30000 pps 之间提高。
- 偏差或转角越大，基础速度越低。
- 右偏仍按K230协议记为正；根据当前底盘实车转向测试，最终差速输出使用
  `LINE_STEERING_OUTPUT_SIGN = -1`。
- 偶发丢失时，以40 mm/s和上次一半转向量保持120 ms；随后仍按该低速进入
  `REACQUIRE`，最多再尝试3 s，用于穿越A/B/C/D大黑圆点造成的短时识别空窗。
- 重新识别到赛道后自动恢复进入圆点前的正常速度或C—D动作速度。
- 视觉帧通信超过180 ms、从未得到过有效赛道，或3 s重捕获仍失败时，PWM清零，
  TB6612 STBY拉低。通信断开不会盲行。

当前巡线最高单轮目标限制为 45000 pps。按 47 mm 轮径和约
41500 count/rev 估算，30000 pps 约为 107 mm/s，45000 pps 约为
160 mm/s。

## 第一次测试顺序

1. 把车轮架空，K230 和 STM32 共地，先不要放到赛道上。
2. 烧录后若 K230 没有发送有效线，两个车轮必须保持不转。
3. 在摄像头画面中央放置黑线。VOFA+ 通道13应变为1，通道17应不低于380。
4. 把黑线向画面右侧移动。通道14和16应变为正；通道11应大于通道12，
   车轮落地后小车应向右转。
5. 把黑线向画面左侧移动。通道14和16应变为负；通道11应小于通道12，
   车轮落地后小车应向左转。
6. 遮住黑线：通道13可短暂变为2，随后必须变为0并停车。
7. 方向全部正确后再落地，先在低速直道验证，再测试弯道。

若第4、5步的误差符号正确但实体转向仍然相反，不要修改K230或速度环，只需将
`line_follow.c` 中的 `LINE_STEERING_OUTPUT_SIGN` 在 `-1` 与 `1` 之间切换。
如果误差符号本身就反了，再检查 K230 的 `CAMERA_HMIRROR` 和
`CAMERA_VFLIP`。

## 主要调参入口

巡线参数位于 `Core/Src/line_follow.c`：

- `LINE_MIN_BASE_PPS`：低置信度和弯道的最低基础速度。
- `LINE_CRUISE_PPS`：直道巡航速度。
- `LINE_MAX_WHEEL_PPS`：巡线允许的单轮最高速度。
- `LINE_LATERAL_KP_PPS_PER_MM`：横向偏移修正强度。
- `LINE_HEADING_KP_PPS_PER_DEG`：航向角修正强度。
- `LINE_MAX_CORRECTION_PPS`：最大差速修正。
- `LINE_STEERING_OUTPUT_SIGN`：实体底盘转向方向，只允许使用 `1` 或 `-1`。
- `LINE_CORRECTION_FILTER_DIVISOR`：转向平滑程度，增大更平稳但响应更慢。
- `LINE_COMM_TIMEOUT_MS`：K230 通信超时停车时间。
- `LINE_LOST_HOLD_MS`：短时丢线保持时间。
- `LINE_REACQUIRE_MAX_MS`：低速重捕获最长时间。

建议每次只修改一个参数。摆动明显时先降低横向/航向增益；入弯太慢时再增加
增益或减小滤波除数；直道稳定后最后提高巡航速度。

视觉标定参数位于 `Car/K230/vision_config.py`。其中
`OPTICAL_CENTER_X` 和 `LATERAL_MM_PER_PIXEL` 必须按摄像头安装位置校准，
否则小车即使控制正常也会持续偏向一侧。

K230已针对A/B/C/D大黑圆点放宽“已跟踪轨迹附近”的宽连通域，同时拒绝启动时
出现的孤立宽黑块。联调时调试画面的 `M` 应在圆点上短暂大于0，`OK`保持有效；
即使少量帧无效，STM32也会低速继续穿越而不是立即停车。

回程累计里程达到7300 mm后，小车把巡线速度降至80 mm/s提高A点捕获率；只在
7300～8062 mm接受终点圆点。若仍漏检，8062 mm触发里程兜底结束，因此不会把
下一处B点圆点误判为A点。
