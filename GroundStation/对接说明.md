# 图形化地面站对接说明

版本：2026-07-31
协议基线：LXS1 v1.1
程序入口：`GroundStation/Software/main.py`

## 1. 已实现能力

- Windows和Ubuntu图形界面，现场运行不需要外网。
- LXS1增量解析，支持串口分包、粘包、错误帧后重同步。
- 使用赛题“打印用”场地图显示飞机和小车位置、航向与轨迹。
- 小车位置以 `CAR_STATE.path_mm` 为主，按
  `A→B→C→D→A` 顺时针赛道换算，不采用有累计漂移的 `CAR_POSE.x/y`。
- 显示任务、飞控、小车、抛投、动态降落、故障和链路状态。
- 自动保存CSV遥测日志并提供原始收发帧窗口。
- 广播 `TASK_ABORT` 时携带当前 `run_id`和 `reason=1`。
- 抛投/动态起降两种无硬件演示，动作均位于C—D段。

## 2. 启动

Windows首次运行可双击：

```text
GroundStation/Software/启动地面站.bat
```

批处理会检查可用Python，必要时建立 `.venv` 并安装依赖。手动运行：

```powershell
cd GroundStation\Software
python -m pip install -r requirements.txt
python main.py
```

Ubuntu：

```bash
sudo apt install python3 python3-tk
cd GroundStation/Software
python3 -m pip install -r requirements.txt
python3 main.py
```

串口固定为 `115200 8N1`。

## 3. 物理链路

飞机—地面站与小车—地面站是两条独立ECB02链路。GUI当前打开一个PC串口，
推荐地面站F103完成汇聚：

```text
飞机ECB02 → F103 UART_A ┐
                       ├→ F103 USB/调试串口 → PC GUI
小车ECB02 → F103 UART_B ┘
```

汇聚固件只转发完整原始字节，不改变 `SRC/DST/MSG/DATA`，不重新封装，不增加
CRC。两路同时到达时按帧为单位排队，禁止字节交叉。PC发出的 `TASK_ABORT`
应原样广播到两路ECB02。

如果现场使用两个USB串口适配器而不使用F103汇聚板，需要先扩展GUI为双COM
输入；当前版本不能同时打开两个COM口。

## 4. 地面站使用的v1.1消息

| 消息 | 来源 | 长度 | 地面站用途 |
|---|---|---:|---|
| `TASK_START 0x10` | 小车 | 6 | 记录 `run_id/task_mode` |
| `TASK_STATE 0x12` | 飞机 | 14 | 全局状态、计时、故障、里程备份 |
| `FC_STATE 0x21` | 飞机/适配端 | 13 | 解锁、高度、速度、电池、故障 |
| `FC_POSE 0x22` | 飞机/适配端 | 8 | 飞机场地坐标 |
| `CAR_STATE 0x31` | 小车 | 13 | 小车状态、循线、速度、里程 |
| `CAR_POSE 0x32` | 小车 | 11 | 仅接收，不覆盖里程推算地图位置 |
| `DROP_STATE 0x50` | 飞机 | 2 | 抛投状态 |
| `LAND_STATE 0x51` | 飞机 | 3 | 动态降落与停留时间 |
| `FAULT 0x60` | 任意节点 | 3 | 事件告警 |

`CAR_STATE`真实布局：

```text
run_id:u8, car_state:u8, speed_mode:u8, line_valid:u8,
speed_mm_s:u16, fault_code:u16, path_mm:u32, lap:u8
```

小车地图关键里程：

```text
A=0 mm
B=1500 mm
C=3856 mm
D=5356 mm
A完成=7712 mm
```

`CAR_STATE`直连里程优先；一秒内收到直连小车状态时，飞机 `TASK_STATE` 中的
转发里程不会覆盖它。

## 5. 飞机必须发送的数据

飞机主控每100 ms向地面站发送：

```text
TASK_STATE:
run_id:u8, task_mode:u8, global_state:u8, result:u8,
fault_code:u16, elapsed_ms:u32, car_path_mm:u32
```

飞控适配层或飞机主控应发送 `FC_STATE`，并以8字节 `FC_POSE`发送场地位置：

```text
x_cm:i16, y_cm:i16, z_cm:i16, yaw_deg:i16
```

抛投和动态降落必须分别发送 `DROP_STATE`、`LAND_STATE`。仅改变
`TASK_STATE.global_state`不足以更新地面站动作详情。

## 6. 坐标与赛道

场地坐标原点为左下角：

```text
X向右：0..400 cm
Y向上：0..500 cm
H点中心约：(112.5, 112.5) cm
A点：(150, 200) cm
```

小车轨迹总长约771.24 cm，位置由累计里程取模后分段计算。抛投、降落小车
和5秒平台停留必须发生在C—D段。
